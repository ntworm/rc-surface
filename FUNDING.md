# Funding

RC Surface is released under the PolyForm Noncommercial 1.0.0 license and free
to install for noncommercial use. The source is public (source-available) and
there is no Pro tier. Donations fund the next round of work; existing features
stay free.

## Where donations go

- Future features: offline MediaPipe bundle, WebRTC multi-phone, WebMIDI.
- New control templates: Drum Rack, Sampler, Wavetable.
- Hardware testing on real stage rigs.
- Maintenance time for stable releases.

## How to fund

- **Gumroad** — pay what you want, suggested R$25, minimum R$0. The link is published in the project README and on the release page. The default is R$0, so the cost is never the barrier. R$25 is anchored to "one hour of dev time saved on setup".
- **Direct support** — only trust funding links published in the official repository (this repo's README and release notes). Do not send money to personal accounts advertised elsewhere.

## Other ways to help

The project is built and tested on commodity gear. Donations pay for the work
on new generations of mobile browser APIs.

Starring the repo, filing issues with reproduction steps and sharing
screenshots or clips on social media help as much as a donation.
