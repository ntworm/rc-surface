documentation lives in `docs/`.

- [dev/LIVE-WRITE-CEILING-1.0.md](https://github.com/ntworm/rc-surface/blob/main/dev/LIVE-WRITE-CEILING-1.0.md) - the write ceiling measured for the 1.0 cycle.
